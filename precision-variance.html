From quote file to verified prices

From quote file to verified prices in six steps

You bring the file; the tool finds the customer, pulls the rates and does the maths.

  1. ConnectPoint the app at your ERP database once and set the fallback rate chart and default metal loss %.
  2. Drop fileDrag in a quotation or sales order spreadsheet; each design in the file gets its own tab.
  3. Auto-priceThe customer is matched from the file and every line is re-priced from their rate chart, falling back to your base chart where they have no rate.
  4. ReviewLines turn green, amber or red by how far the quote is from master, with totals and counts for the whole design.
  5. Drill inDouble-click any line to see exactly how its master price was built, and fix the formula on the spot.
  6. ExportSave a copy of the original file with each problem cell coloured in, layout untouched.

One App, Three Jobs

Check every quote, control how prices are worked out, and look up rates and orders without opening the ERP.

Check

BOM Comparison

Drop a spreadsheet and every metal, stone, stone setting, setting labour, other labour, finding and chain line is compared with the master price. Lines within 5% are green, 5–15% amber, over 15% red, and lines with no master rate grey. A summary shows template total, master total, the difference and how many lines fall in each status.

Multi-Design Orders

Sales orders with many designs open as one tab per design, skipping the order summary sheet. Tabs with a real price difference are highlighted, and a search box narrows the list to the design you need.

Line Breakdown

Double-click any line to see each step of its master price: where every number came from, what was done to it and the running total. If the customer had no rate of their own, the line says it used the base chart.

Highlighted Export

Export writes a copy of the file you dropped in with each line's own cells filled in its status colour. A stone and its setting on the same row are coloured separately, so you can see which one is wrong.

Price

Pricing Formulas

Each of the nine cost types (metal, diamond, colour stone, finding, per-piece labour, per-gram labour, diamond-weight labour, stone setting, chain) has a readable formula. Edit it with a step-by-step builder or as plain text, add an override for one customer, or reset to the built-in default.

Custom Variables

Point a new variable at any table and column in your ERP, choose how it matches each line, and it appears in every formula dropdown. New pricing masters can be used without a software update.

Costing Settings

Set the customer code (or let the app detect it from the file), a base rate chart to fill gaps, and a default metal loss %. The customer's own loss % is used whenever the ERP has one.

Look up

Customer Rate Card

Pick any customer and load every material and labour rate on file, with size or weight bands and per-piece or per-gram basis, in two tabs.

Order Pipeline

A live list of open quotations and sales orders with order date, expected delivery and value. Each one is marked Open, Overdue or Delivered, and you can filter by customer and type or include delivered orders.
